# Govee2MQTT (2FA Fix)

Bridge for [Govee](https://govee.com) devices to Home Assistant via the
[MQTT Integration](https://www.home-assistant.io/integrations/mqtt/), with
support for the **March 2026 server-side 2FA / email-verification login flow**
that broke `wez/govee2mqtt`.

Use this fork only if you hit `status 454` in the upstream add-on logs.
When upstream merges 2FA support, switch back.

See the **Documentation** tab for setup, the 2FA flow, and configuration
reference.
